# CONTEXTO DEL PROYECTO - MUNDO SANO

## Proyecto
**Mundo Sano** - Iniciativa de gestión de salud/bienestar desarrollada por UNSADA, con una arquitectura dividida en un Backend robusto y una aplicación móvil/web integrada.

## Stack Principal
- **Frontend:** Ionic Framework (v6+) con React 18 y Capacitor.
- **Backend:** Java 17, Spring Boot 3.0.6.
- **DB/Otros:** MySQL (v8) con JPA/Hibernate y Gson para serialización.

## Estado y Foco Actual
El objetivo actual del desarrollo es:
1. Sincronizar la lógica de negocio entre el Backend (Java) y el Frontend (Ionic/React).
2. Facilitar la creación y seguimiento de tareas (TODOs) para ambos entornos.

## Integraciones y Dependencias Externas
- **Actuales:** Capacitor SQLite, Geolocation, Network, Axios.
- **Futuras:** Sincronización offline-first mejorada y analíticas.
